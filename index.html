01 · Founder · Aug 2026 – now

Karana

An app that teaches the meaning behind Hindu prayers, festivals, and verses. A small team and I started it in August 2026, and it’s on the App Store and Google Play.

The content is the product. I localized 58 prayers and 70 festival guides into 11 languages, so people who don’t read English can still read and recite them, and generated 10,000+ narration clips offline with open-source Indic text-to-speech in PyTorch, at no per-use cost.

Underneath it is an Express API on Supabase Postgres. I wrapped the web app with Capacitor and RevenueCat to ship iOS and Android apps with in-app purchases. The phone on the desk is running it: the kindled light is a streak, and the sadhana list is the day’s practice. The laptop is counting up the numbers.

02 · Software engineer · Aug 2026 – now

Real health records, on a phone

The backend for a patient app that reads real medical records from Cerner, through SMART on FHIR. The whiteboard is how it signs in.

I set up SMART on FHIR backend auth for the Flask API: RS384-signed JWTs, a hosted JWKS the server publishes, and six scopes, so the app can read a patient’s record without a person logging in each time.

Then I made the data make sense. Cerner returns 742 medication records for the test patient; I filter them by intent and status so the patient sees only the 14 active orders. I also drafted the JSON contracts for four app tabs and coded the async Swift client, so the backend and app teams could build in parallel.

04 · Machine learning engineering intern · Jun – Aug 2026

Politheon

Will a bill pass? I trained the model that predicts it, and made sure its score holds up on bills it has never seen. The Capitol is under the window.

I trained LightGBM on 4,200 TF-IDF features from the bill text plus 10 engineered features, which raised bill-passage accuracy by 15%.

The first score was too good to trust. I partitioned the train and test sets by bill and removed a source of label leakage, so the 83% macro F1 holds on unseen bills. I also indexed 2,000 bills with SQLite FTS5 and LSA so people can search them by keyword and by meaning.

06 · Infrastructure · Jan – Apr 2026

B2Alpha

Lets AI agents message each other and pay businesses. The rack in the corner is the relay.

Agents shouldn’t have to scrape websites to talk to each other. Go routing nodes relay their messages over gRPC, and every node verifies the sender’s Ed25519 signature against a Rust key registry on PostgreSQL before forwarding anything, so spoofed agents are blocked.

Payments run through Stripe Connect via Supabase edge functions, so agents can pay businesses on their own, and the Python and TypeScript SDKs ship with 84 tests so outside developers can plug their agents in.

09 · Developer tools · HackGT 13

Vibez

A visual language on top of JavaScript, where your codebase is a node graph built from what actually ran. That’s what’s on the monitor.

Vibe-coded projects are easy to make and hard to understand. Vibez shows the program as the graph of what executed, so you can read it and edit it in place.

I built the multiplayer side: each teammate’s own AI agent shares presence, file claims, and live edits over Supabase, so people and agents work on one project without stepping on each other.
